# DESIGN.md — 펫과함께 디자인 규칙 (M1)

> 선택 스타일: **A. Warm Clay(말랑한 점토)** — Stitch 프로젝트 `펫과함께 M1` (ID `6742515804383995325`)
> Stitch 원문 규칙: [stitch/stitch-design-system.md](stitch/stitch-design-system.md)
> 이 문서가 기준이고, Stitch 원문과 다르면 **이 문서를 따른다.**

## 1. 분위기

- 폭신한 점토로 빚은 듯한 입체감: 둥근 모서리, 아래쪽이 두꺼운 버튼, 따뜻한 그림자
- 크림 배경 위에 흰 카드를 올리고, 강조는 코랄 하나로 모은다
- 배경에는 아주 옅은 점 무늬(도트)를 깔아 손으로 만든 느낌을 준다
- 피할 것: 어두운 분위기, 날카로운 모서리, 검은 그림자, 기존 게임을 떠올리게 하는 모양

## 3. 글꼴

- **한글 둥근 글꼴 우선**: Pretendard 또는 Noto Sans KR. Stitch 시안은 Plus Jakarta Sans와 Noto Sans KR을 함께 씀
- 숫자(타이머, 능력치)는 굵게(700~800)
- 한글 줄 간격은 1.5~1.6

| 단계 | 크기 / 굵기 | 예 |
|---|---|---|
| 큰 제목 | 28px / 800 | "태어났어요!" |
| 제목 | 20~24px / 700 | 몬스터 이름, 화면 제목 |
| 본문 | 14~16px / 500 | 안내 문구 |
| 라벨 | 12~14px / 700 | 버튼, 칩 |
| 작은 글자 | 12px / 500 | 도움말 |

## 4. 모양과 간격

- 모서리: 버튼·칩·입력칸 = 완전히 둥글게(`9999px`), 카드 = `32px`, 작은 칸 = `20px`
- 화면 좌우 여백 `20px`, 요소 사이 기본 간격 `16px` (8px 단위)
- 화면 너비 기준 `390px`, 넓은 화면에서는 가운데 `480px` 이하로 고정

### 그림자(입체감 3단계)

| 팝업 | `0 12px 32px rgba(89,62,34,.18)` + 뒷배경 `rgba(59,47,47,.45)` 흐림 4px |

## 5. 공통 UI 부품

| 부품 | 규칙 |
|---|---|
| 기본 버튼 | 코랄 배경, 흰 글자, 아래 테두리 `primary-rim`. 누르면 3px 내려가고 아래 테두리가 얇아짐 |
| 보조 버튼 | 민트 배경(또는 흰 배경 + `border` 테두리), 짙은 글자 |
| 비활성 버튼 | 기본 버튼에 투명도 50%, 누를 수 없음 (07 이름 짓기 참고) |
| 링크형 | 배경 없음, 코랄 글자 + 작은 아이콘 ("이메일 다시 입력") |
| 입력칸 | 흰 알약 모양, 테두리 `border`, 안쪽 옅은 그림자. 포커스 시 테두리 코랄. 오른쪽에 글자 수(`0/10`) |
| 코드 입력칸 | 6칸으로 나눈 둥근 사각형, 현재 칸은 코랄 테두리 (02 참고) |
| 오류 문구 | 입력칸 아래 작은 빨간 점 + `error` 색 글자. 입력칸 테두리도 옅은 빨강 |
| 카드 | 흰 배경, 테두리 `border`, 모서리 32px |
| 상단 바 | 왼쪽 "펫과함께" + 발바닥 아이콘(코랄), 오른쪽 닉네임 알약 |
| 능력치 막대 | 높이 12~16px 알약, 바탕 `track`, 위쪽 절반에 옅은 광택. 오른쪽에 숫자 |
| 상태 배지 | "✨ 빛나는 몬스터" = `honey` 배경 알약 |
| 준비 중 칸 | 점선 테두리 카드 + 자물쇠 + "준비 중이에요" / "곧 만나요" |

## 7. M1에서 빼는 것 (Stitch가 임의로 넣은 요소)

시안에 보여도 **M1에서는 만들지 않는다.**

- 재화(도토리, 햇살조각), 하단 탭 메뉴(보육실·도감·산책·가방·설정)
- 따스함 지수 게이지, 돌봄 횟수, 실내 온도, 친밀도, 도감 번호, 공유 버튼
- 닉네임·이름 추천 칩, "단계 3/3" 표시, 코드 남은 시간 표시
- 06 화면의 영어 문구("HATCHING NURSERY", "HATCHED SUCCESSFULLY!")와 05 화면의 깨진 글자("RKLES")
- 09 화면의 "속성 & 희귀도 도감 프리뷰" 칸은 **부품 견본**이다. 화면에 넣지 말고 부품 규칙(속성 아이콘, 알 등급 칩)으로만 참고한다
- 능력치 라벨의 영어 약자(HP, ATK 등)는 빼고 한글만 쓴다

## 8. 캐릭터 표시 규칙

- 몬스터와 알은 **레이어 SVG**로 그린다. 시안의 몽실 그림(06~09)은 분위기 참고용이다
- 굵고 깔끔한 짙은 갈색 외곽선, 단색 면 + 약한 음영, 큰 눈, 볼 터치
- 홈에서 몬스터는 숨쉬기(살짝 커졌다 작아짐) + 통통 튀기, 발밑에 옅은 타원 그림자
- 부화 가능 상태의 알은 좌우로 흔들림 + 금빛 후광 + 반짝이
- 상세 캐릭터 시안은 `design/characters/`에 넣는다 (stitch-brief.md 4장 참고)

## 9. 참고용 코드를 쓸 때 주의할 점 (보안)

Stitch가 내보낸 HTML은 **화면 뼈대 참고용**이고, 그대로 배포하지 않는다.

- `cdn.tailwindcss.com` 스크립트를 외부에서 불러온다. 운영 코드에서는 외부 스크립트를 쓰지 않는다 (공급망 공격 위험)
- `lh3.googleusercontent.com`의 외부 이미지를 쓴다. 운영 코드에서는 자체 SVG와 에셋만 쓴다
- Google Fonts는 직접 내려받아 자체 서버에서 제공(self-host)하는 방식을 권장한다
- 모든 입력(이메일, 초대 코드, 인증 코드, 닉네임, 몬스터 이름)은 서버에서 다시 검증한다. 화면에 보여 줄 때는 HTML로 해석되지 않게 이스케이프한다
