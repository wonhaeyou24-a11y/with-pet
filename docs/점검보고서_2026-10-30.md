## 가장 중요한 문제 (게임 구조)

1. **M2·M3가 서버에 배포되지 않았다.** Supabase에는 테이블 4개(players, invite_codes, eggs, monsters)와 함수 2개(redeem-invite, egg v1)뿐이다. `supabase/migrations/…_m2_…sql`, `…_m3_…sql`과 `supabase/functions/care`는 파일만 있고 적용·배포되지 않았다. `care` 호출은 CORS/404로 실패하고 앱은 로컬 대체 로직으로 동작한다.
2. **서버 판정 원칙 위반.** `src/lib/api.ts`의 `callEgg`가 서버가 없거나 `not_ready`면 클라이언트에서 직접 부화 결과를 굴리고(`rollDessertMonster`), 부화 시간도 1분(`TEST_HATCH_MS`)으로 고정한다. 브라우저 저장소(`withpet_local_monsters_v2`)를 고치면 능력치·종족을 바꿀 수 있고, 서버(DB)에는 몬스터가 쌓이지 않는다.
3. **지인 기능이 가짜다.** 광장·대전 상대는 `PLAZA_SHOWCASE_FRIENDS`(고정 NPC)다. 지인의 실제 몬스터는 보이지 않는다.
4. **테스트 모드가 배포본에도 열려 있다.** `?dev=true` 또는 `localStorage.dev_bypass=true`면 로그인 없이 게임 화면이 열린다. 설정 메뉴에 "테스트용 1분 디저트 알 리셋"도 모든 사용자에게 보인다.

## 화면 짤림·표시 문제

| 화면 | 문제 |
|---|---|
| 메인 홈 상단 HUD | 닉네임 "초코마스터"가 두 줄로 꺾임, 코인 "520"·"150"이 숫자 중간에서 줄바꿈, "Lv.1 파티시에"가 잘림. 부티크 헤더의 리본 코인 "150"도 같은 문제 |
| 메인 홈 말풍선 | 말풍선·알림 문구가 잘림 ("주인님! 오늘 몸이 가벼워요! 크런치…") |
| 메인 홈 문구 | 이름 뒤 조사 오류: "빠작이이가" (이름이 '이'로 끝날 때 "이가"를 한 번 더 붙임) |
| 광장 | 헤더 코인 칩 "🪙 520"이 잘림, 확대율 "85%" 버튼이 줄바꿈 |
| 알 화면 (세로가 긴 폰) | 알이 둥지 위에 떠 있음 (알과 둥지 사이가 벌어짐) |
| 첫 로딩 | 몬스터·광장 캐릭터가 하얀 네모로 보이다가 수 초 뒤에 나타남 (3D 준비 중). 앱 첫 화면도 서버 응답을 기다리는 동안 빈 화면 (로딩 표시 없음) |

3D 로딩은 이 테스트 브라우저(초당 2프레임 수준)에서 측정한 값이라 실제 폰은 더 빠를 수 있다. 다만 화면마다 WebGL을 새로 만들어서 저사양 폰에서는 같은 현상이 길어질 수 있다. 3D 준비 전에 2D 그림을 먼저 보여 주는 것을 권한다.

정상으로 확인한 화면: 알(대기/부화 가능), 부화 연출, 이름 짓기, 돌보기·토핑 가방, 파티세리 훈련, 식감 스킬트리, 나만의 미니룸, 부티크 상점, 디저트 도감, 미션, 설정 메뉴.

## 사운드 보완 (이번 작업)

**원인**: 기존 소리 17종은 "필터를 거친 노이즈 덩어리"(`playFractureCluster`)와 "젖은 노이즈"(`playWetSquishFoley`) 두 재료의 주파수만 바꾼 것이라 서로 비슷하게 들렸다.

**방법**: 디저트마다 물리적으로 다른 재료와 시간 구조로 새로 합성했다 (`src/lib/soundSynth.ts`).
- 껍질·쿠키: 입자 수십~수백 개의 군집 / 물방울·과즙: 올라가는 음높이의 기포 / 나무·유리·도자기: 감쇠하는 사인의 합 / 반죽: 필터가 움직이는 노이즈 + 저음 눌림 / 젤리·푸딩·카멜레온: 미끄러지는 음높이 / 탄산: 미세 기포 / 스프링클: 점점 빨라지는 알갱이
- 매번 살짝 다르게 들리고(3가지 변형을 돌려 재생), 연타하면 소리가 조금씩 높고 빨라진다. 스테레오와 작은 방 울림, 마스터 볼륨·압축기를 거쳐 겹쳐도 찢어지지 않는다.

**왁뿌볼** (`wax-pop`): 왁스 코팅 볼을 깨뜨리는 놀이(겉은 단단한 왁스, 속은 말랑한 점액, 깨질 때 "아그작")를 기준으로 만들었다. 꾹 눌리며 끽 → 아-그-작 세 번에 나눠 깨짐(묵직한 '턱' 포함) → 부스러기 후두둑 → 속 점액이 기포와 함께 쭈욱 → 끈적하게 떨어지는 마지막 "쩍".

**검증**: `npm run sound:lab`이 17종을 분석한다 (길이, 음량, 무게중심, 대역별 에너지, 타격 수, 음정감, 서로 비슷한 정도). 직접 들을 수 있는 `design/sounds/*.wav`와 스펙트로그램 시트(`spectrogram-sheet.png`)도 만든다. 청음실에서 17종 전부 재생 오류 없음을 확인했다.

한계: 귀로 직접 듣고 고른 것이 아니라 합성과 분석으로 만든 소리다. 마음에 안 드는 소리는 `soundSynth.ts`의 해당 레시피 숫자를 고치면 바로 바뀐다.
