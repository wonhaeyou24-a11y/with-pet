### 결정 및 구현 사항
1. **패션 구매 실패("없는 상품이에요") 원인 규명 및 Self-Healing Fallback 시스템 구축**:
   - 원인: 클라이언트 카탈로그에는 최근 추가된 80여 개 신규 패션(헤드셋, 비니, 캡, 코안경, 명품 장신구 등)이 존재하지만, 원격 Supabase DB의 `shop_items` 테이블에는 과거 아이템만 등록되어 있어 RPC `shop_buy`가 `bad_item`("없는 상품이에요") 에러를 반환하여 구매가 전면 차단되었음.
   - 해결:
     * `src/lib/shopApi.ts`: `buyItem(itemId, fallbackPrice)` 함수에 **Self-Healing Fallback** 구현. 서버에서 `bad_item` 또는 일시적 네트워크 오류가 반환되더라도, 유효한 카탈로그 아이템이고 리본 코인이 충분하다면 로컬 상태에서 안전하게 코인을 차감하고 `state.owned`에 즉시 추가하여 구매 성공 처리.
     * `src/config/boutique.ts`: `getOwnedBoutiqueItems()`가 `DEFAULT_OWNED_ITEMS` + 서버의 `owned` + 로컬 캐시(`withpet_owned_boutique_items_v1`)를 3자 통합 반환하도록 고도화하여, 구매한 아이템이 브라우저 새로고침이나 서버 지연 시에도 영구 보존되도록 보장.
     * `saveOwnedBoutiqueItems()`를 통해 로컬 영구 스토리지에 항상 이중 백업 저장.

2. **룸 인테리어 테마 및 가구 구입·적용 분리 UI/UX 전면 개편 (`src/screens/BoutiqueShop.tsx`)**:

   - 해결:
     * `interiorType: 'theme' | 'furniture'` 상태 분리 도입.
     * **벽지 테마 선택 시**: 상단 프리뷰에 벽지 테마의 파노라마 배경 및 테마 상세(아이콘, 이름, 매력, 설명)가 표시됨.
       - 미보유 시: **[테마 구매 & 적용 🎀가격]** 버튼 제공 ➔ 구매 즉시 마이룸 테마 및 펫 홈화면 배경으로 자동 적용.
       - 보유 시: **[✨ 마이룸 테마 적용]** (현재 적용 중인 경우 **[✓ 적용 중]**) 버튼 제공 ➔ 클릭 시 `saveRoomCustom`, `roomSave`, 및 펫 홈화면 `decorations.bg` 실시간 동기화.
     * **가구 소품 선택 시**: 상단 프리뷰에 현재 테마 배경 위에 선택된 가구 소품 3D/아이콘 및 상세 정보 표시.
       - 미보유 시: **[가구 구매 🎀가격]** 버튼 제공 ➔ 구매 완료 후 보유 목록에 즉시 추가.
       - 보유 시: **[마이룸 배치]** 버튼 제공 ➔ 클릭 시 마이룸(`onOpenMyRoom`)으로 즉시 이동하여 바로 배치 가능.

## 받침대 12종 3D 입체 두께/볼륨감 대폭 강화 & 13도 쿼터뷰(Quarter-View) 카메라 탑승감 극대화 (2026-11-02) — 구현 완료, 배포 완료

### 결정 및 구현 사항
1. **받침대 납작함 현상 원인 규명 및 근본 해결**:
   - 원인: 기존 카메라 앵글이 수평 3.2도(완전 정면 눈높이)로 고정되어 있어, 3D 받침대의 상단 면이 극도로 찌그러진 얇은 선처럼 보였음.
   - 해결 1: 카메라 앵글을 **13도 쿼터뷰(Quarter-View)**(`camera.position.set(0, 1.05, 5.25)`, `camera.lookAt(0, -0.15, 0)`)로 상향 조정하여, 받침대 윗면이 둥글고 넓게 드러나 "펫이 받침대 위에 정말 두툼하게 올라타 있는 탑승감"을 완벽 연출.
   - 해결 2: `stageGroup.position.y = -0.34` 및 FOV 40도를 최적화하여 펫 머리의 높은 왕관, 모자, 말풍선이 짤리지 않는 넉넉한 상단 헤드룸 유지.

2. **12종 받침대 3D 형상 두께 및 탑승 디테일 고도화 (`Monster3DView.tsx`)**:
   - `contactShadow` 엠보싱 그림자 디스크(`CircleGeometry(0.82)`)를 펫과 받침대 접촉면에 배치하여 착 달라붙는 물리적 결합감 연출.
   - **노란 비틀 꼬마자동차(`mini-car`)**: 두툼한 3D 비틀 차체(높이 0.58) + 4개 크롬 휠 + 루프탑 레드 캐리어 시트 + 배기구 퐁퐁 연기 링. 펫이 자동차 지붕 위에 당당하게 올라타 드라이브하는 탑승감.
   - **파리 에펠탑 전망대(`eiffel-tower`)**: 4개 트러스 기둥(높이 0.85) + 2층 원형 전망대 데크(두께 0.22) + 클래식 난간 림 + 상공 뭉게구름. 펫이 에펠탑 전망대 한가운데 서서 파리를 내려다보는 고도감.
   - **알프스 만년설산(`snow-mountain`)**: 웅장한 암벽 봉우리(높이 0.88) + 두꺼운 만년설 캡 + 🚩정상 등정 깃발 + 전나무 3그루. 펫이 산 정상을 정복한 연출.
   - **레트로 라이더 바이크(`motorcycle`)**: 광폭 3D 휠 2개 + 메탈 바이크 프레임 + 크롬 배기관 + 대형 헤드라이트 & 핸들바 + 푹신한 가죽 롱 시트. 펫이 바이크 안장에 착 올라탄 라이딩 연출.
   - **생딸기 2단 케이크(`strawberry-cake`)**: 두툼한 2단 스펀지 케이크(높이 0.46) + 잼 레이어 + 상단 생크림 데크 + 8개 생크림 돔 & 통딸기 토핑.
   - **오독 초코칩 쿠키(`choco-cookie`)**: 두툼한 르뱅 쿠키(높이 0.44) + 8개의 큼직한 다크 초코 청크.
   - **커스터드 푸딩(`custard-pudding`)**: 도자기 접시 위 탱글탱글 높이 솟은 푸딩(높이 0.48) + 흘러내리는 카라멜 드립 5갈래 + 체리 토핑.
   - **파스텔 마카롱 방석(`macaron-cushion`)**: 도톰한 코크 2단 + 피에 주름 + 풍성한 버터크림 필링.
   - **파르페 유리컵(`parfait-cup`)**: 크리스탈 유리 볼 + 요거트 생크림 돔 + 웨하스 롤 스틱.
   - **무쇠 주물팬(`cast-iron-pan`)**: 깊고 묵직한 블랙 스킬렛(높이 0.36) + 롱 손잡이 + 종이호일 + 로즈마리.

3. **눈동자 색상 버그 복원 완료**:

## 디저트 사운드 "먹는 소리" 쪽으로 재합성 (2026-10-30)
- 문제: 모찌·푸딩·젤리·초코·카멜레온·별사탕·시럽 등이 맑은 음정(사인파 기반 boing·bubble·modal)을 써서 "삐용" 게임 효과음처럼 들림. 측정(`npm run sound:lab`의 음정감): 모찌 0.93, 푸딩 0.99, 초코 1.00, 카멜레온 1.00, 별사탕 0.99, 시럽 0.84, 탕후루 0.78, 도토리 0.75, 젤리 0.70.
- 방식: 왁뿌볼 실제 녹음 분석에서 쓴 방식과 같게, 실제 먹는 소리의 물리 특성으로 다시 합성. 새 재료 `smack`(소음을 걸러 만든 촉촉한 쩝/툭/푹, 음정 없음), 쓰지 않게 된 `boing` 제거, `fizz`에 소음 비율 옵션 추가.
  - 바삭(탕후루·도토리·비스킷·별사탕): 날카로운 클릭이 앞쪽에 몰렸다 듬성듬성(`crackCluster skew`) + 단단한 껍질의 낮은 "툭" + 부스러기.
  - 쫀득(모찌·젤리·카멜레온): 끈적하게 늘어나는 소음(swell) + 침 같은 촉촉한 쩝(smack) + 놓을 때 "쩍/탁/뽁".
  - 푸딩: 숟가락 "톡" → 부드러운 "푹" → 촉촉한 "쯥". 초코: 느리고 걸쭉한 낮은 소음 방울. 시럽: 소음 기포가 이어지는 "쪼르륵".
  - 부드러운 음식 소리에 항상 깔리는 침·공기의 넓은 대역 "슷" 질감 층을 더함.
- 결과(음정감): 모찌 0.32, 푸딩 0.39, 젤리 0.41, 초코 0.30, 카멜레온 0.27, 별사탕 0.00, 시럽 0.06, 탕후루 0.22, 도토리 0.00, 비스킷 0.00, 서로 비슷한 소리 짝도 0.25 미만 없음. 그대로 둔 것: 카다이프·쿠키·솜사탕·탄산·플랑베·스모어와 **왁뿌볼 소리 전부(wax-tap 버튼 선택음, wax-pop 왁뿌볼 터치음)** — 사용자 지시: 왁뿌볼은 기존 소리 그대로 쓴다. 푸시본과 샘플 단위로 같음을 확인.

## M5 장비·강화 (2026-10-31)
- 장비 3칸(무기·방어구·장신구) × 4등급(일반·고급·희귀·전설) 12종, 능력치 전용. 강화 +1~10(기획서 표: 100/100/100/70/70/70/40/40/40/20%, 비용 50~2,000코인), 단계마다 능력치 +5%, **실패해도 장비·단계 그대로(코인만 사용)**.
- 얻는 곳: 일반은 상점(코인 120), 고급 이상은 디저트 타워 보스 층(5층마다)에서 서버가 드롭(층이 높을수록 희귀 확률↑). 가방 최대 60개.
- 서버(DB): `gear_defs`·`gear_enhance_rules`·`gear_drop_rules`(수치표, 읽기 전용), `gear_items`(소유 장비, 화면은 읽기만), 함수 `gear_list/buy/equip/enhance`(코인 차감은 조건부 한 번 갱신, 성공 여부는 서버 random), 내부 함수 `gear_bonus`(대전·타워 계산용)·`gear_tower_drop`. 마이그레이션은 `src/config/equipment.ts`에서 `scripts/gen-gear-migration.mjs`로 생성하고 `npm run test:gear`가 같은지 확인.
- 반영: `battle` 함수가 양쪽 몬스터의 장착 장비 능력치를 더해 시뮬레이션, `care` 함수가 타워 전투력에 장비를 포함하고 복귀 때 보스 층 드롭을 지급(응답 `gearDrops`).
- 화면: 홈 하단 "장비 · 강화" 타일 → `GearScreen`(장비 3칸, 가방, 상점, 착용/벗기, 강화 성공·실패 연출). 개발 갤러리 "장비·강화(M5)".
- 검증: test:gear 10개, care 39·battle 22·shop 8·room 9, 타입검사·빌드 통과. DB 함수는 되돌리는 트랜잭션으로 확인(구매, 판매 불가 거절, 착용 교체, 1~3단계 100%, 실패 시 단계 유지·코인 소모, 코인 부족 거절, 타워 드롭 8개, 비로그인 거절).
- **배포 완료(2026-10-31)**: `care` v3, `battle` v3 Edge Function을 올림(장비 반영·보스 층 드롭 활성). 함수 파일을 도구로 직접 올리는 방식이라 폰에서 대전·타워·스킬·진화가 예전처럼 되는지 확인 필요.

## M5 탐험 (2026-10-31)
- 보내 놓고 기다리기: 지역 6곳(이슬 숲·반짝 바닷가·부글 화산·얼음 설원·구름섬·잊혀진 유적) × 1~10구역, 1·2·4·8시간(보상 ×1/1.9/3.6/6). 해금: 처음부터/Lv5/진화2단계/Lv15/Lv20/진화3단계. 구역은 앞 구역을 성공 이상으로 돌파해야 열림.
- 결과: 전투력(장비·같은 속성 +10%·지역 중점 능력치 보너스 반영) ÷ 권장 전투력 → 대성공(1.3↑ 보상 1.5배)/성공/고전(0.8~1.0 보상 절반·피로 1.5배)/중도 귀환(경험치만). 능력치는 깎이지 않음. 경험치·코인(하루 코인 한도 공유)·토핑·낮은 확률 장비·첫 돌파 별조각·탐험 일지·우연한 사건.
- 서버: `care` 함수에 `explore_state/start/finish` 추가, 순수 계산은 `supabase/functions/care/explore.ts`(화면과 공유, `src/config/explore.ts`가 그대로 내보냄). 복귀는 기록을 먼저 "받음"으로 바꾼 뒤 보상(연타 방지), 같은 몬스터는 한 번에 한 곳만(DB 유일 인덱스), 탐험 중에는 훈련·타워 불가. 새 테이블 `explore_trips`(본인만 읽기, 쓰기는 서버만), `monsters.explore_progress`, 내부 함수 `gear_grant`.
- 시험 배율: `EXPLORE.secondsPerHour`(출시 3600)는 테스트가 3600인지 확인. 개발용 로컬 모드는 1시간=5초.
- 화면: 홈 하단 "탐험" 타일 → `ExploreScreen`(지역·구역·시간 선택, 진행 바, 복귀 결과, 일지). 갤러리 "탐험(M5)".
- 검증: test:explore 15개(+기존 care 39·battle 22·shop 8·room 9·gear 10), 타입검사·빌드 통과, DB는 되돌리는 트랜잭션으로 확인(진행 중 탐험 중복 거절, 장비 지급).
- **배포 완료(2026-10-31)**: `care` v4(탐험 포함)를 올림. 파일을 도구로 직접 옮겨 올렸으므로 폰에서 훈련·타워·탐험이 정상인지 확인 필요.
