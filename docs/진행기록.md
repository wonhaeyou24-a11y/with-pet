# 진행 기록

## M0 (준비) — 진행 중

### 결정 사항
- 게임 이름: **펫과함께** (임시 이름 아님, 우선 이 이름으로 시작)
- 로그인: 이메일 6자리 코드 (OTP). 아이폰 홈 화면 앱에서 매직링크가 안 넘어오는 문제를 피하기 위해 링크 대신 코드 입력 방식.
- 가입: 초대 코드 필수. `redeem-invite` Edge Function이 코드를 선점하고 계정을 만든다. Supabase 대시보드에서 "Allow new users to sign up"을 꺼서 다른 경로의 가입을 막는다.
- `players`의 코인·별조각·랭크 점수는 클라이언트가 쓸 수 없다 (컬럼 권한으로 닉네임만 허용).
- 기획서 원본은 `docs/몬스터 육성 게임 기획서.docx`, 변환본이 `docs/기획서.md`.

### 현재 상태 (2026-10-29): M0 완료
- Supabase(`hajsapkhbnjtgsarvjsz`, 프로젝트2)에 마이그레이션과 `redeem-invite` 함수 적용, 초대 코드 10개 발급, GitHub(`wonhaeyou24-a11y/with-pet`)
- 사용자가 대시보드에서 설정: 가입 끄기, Magic link 템플릿(`{{ .Token }}`), Gmail SMTP, **Email OTP Length 6** (Supabase 기본은 8자리라 바꿔야 함)
- 배포: https://with-pet.vercel.app/ (Vercel, 환경변수 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`)
- 폰 확인 완료: 초대 코드 가입 → 이메일 6자리 코드 → 닉네임 → 홈 화면, 코드 없이 재로그인, 코드 없는 신규 가입 차단, 사용된 코드 재사용 차단
- 참고: 기존 가입자는 초대 코드 없이 로그인할 때도 이메일로 인증 코드를 받아 입력한다 (비밀번호가 없는 구조라 의도된 동작)
- 내장 브라우저에서는 Supabase 로그인이 유지되지 않아 대시보드 설정은 직접 해야 함
- 다음: M1(부화). 사용자가 시작을 말하면 구현 계획부터 보여준다.
